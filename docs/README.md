## 四、阅读提示

- **涉及状态判断的段落请留意文首日期**。相机、数据格式两条线在项目推进中经历过多轮结论变更，
  文档按写作时间记录当时的判断，最新的权威结论统一以
  [`../scripts/collect/相机取图根因结论与修复方案.md`](../scripts/collect/相机取图根因结论与修复方案.md)
  和 [`复现指南.md`](复现指南.md) 第六节为准。
- 各专题文档中标注了「后续进展」的段落，是后期补充的更新，优先级高于同篇正文中更早的结论。
