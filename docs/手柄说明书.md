# 手柄遥操作说明书 — OrcaLab 双臂机器人

> 适用程序：`<项目目录>`
> 手柄：Flydigi Vader 5 Pro（XInput 模式，识别为 Xbox 360 Controller）
> 控制方式：末端**速度式**（推摇杆 = 末端匀速移动，松手即停）

---

## 0. 一分钟快速上手

1. 确认 OrcaLab 里场景已打开、仿真在运行（程序会自己接管）。
2. 启动程序：
   ```
   <你的orcalab环境>\python.exe -X utf8 -u teleop.py
   ```
   看到 `teleop running. active arm = R` 就绪。
3. 页面里机器人双臂抬到工作位、夹爪张开，正对桌面。
4. **动一下手柄唤醒它**（休眠时读不到，动一下就好）。
5. 默认控制 **右臂**。开始操作：
   - 左摇杆推前 → 末端向前（朝桌子）
   - 左摇杆推左 → 末端向左
   - **RT 上升 / LT 下降**
   - 右摇杆 → 转手腕朝向
   - **A 闭合夹爪 / B 张开夹爪**
   - **X 切换左/右臂**

## 1. 按键总表

### 摇杆与扳机（运动）

| 输入 | 方向 | 作用 |
|---|---|---|
| 左摇杆 ↑↓ | 前 / 后 | 末端沿机器人**正前方**（朝桌子）移动 |
| 左摇杆 ←→ | 左 / 右 | 末端沿机器人**左侧 / 右侧**移动 |
| **RT**（右扳机） | — | 末端**上升** |
| **LT**（左扳机） | — | 末端**下降** |
| 右摇杆 ←→ | — | 手腕 **yaw**（左右转） |
| 右摇杆 ↑↓ | — | 手腕 **pitch**（上下俯仰） |
| **RB** / **LB** | — | 手腕 **roll** 正转 / 反转 |

> 所有方向都是**机器人自身坐标系**，不是屏幕方向。推"前"永远是朝机器人正前方。
>
> **从机器人背后视角操作时**左右/前后会感觉相反，见下面的“视角方案”，不用改代码。

### 视角方案（可选）

启动时加参数，或在运行中按 **右摇杆（R3）** 即时切换：

| 启动方式 | 效果 |
|---|---|
| `python teleop.py` | 默认，和以前完全一样（机器人自身坐标系） |
| `python teleop.py --behind` | 从对面 / 背后看：左右 + 前后一起翻转 |
| `python teleop.py --flip-lr` | 只有左右感觉反 |
| `python teleop.py --flip-fb` | 只有前后感觉反 |

> 上下（RT / LT）不受任何方案影响。
> 切到镜像方案后，日志里 `active arm` 会额外显示该臂在屏幕上的左右位置。
> **右摇杆（R3）** 在当前方案和默认方案之间来回切，方便现场对比。

**已确认的现场配置（2026-09-23 实测）**：相机从机器人**背后**看时，用
`--flip-lr` 可让左右、前后、手腕 yaw / pitch / roll **五个方向全部正确**。

> 注意 `--behind` 会**同时翻转左右和前后**。如果只有左右反、前后本来就对
> （背后视角的常见情况），应该用 `--flip-lr`，用 `--behind` 会把前后翻反。

**手腕旋转的修正说明（2026-09-23）**：手腕改为绕**末端自身轴**旋转
（原来是绕世界固定轴），并让 yaw 跟随视角镜像。修正前表现为"往右推右摇杆、
手腕却往左转"，且姿态越歪手感越怪。此问题**按 R3 切换视角无法解决**，
必须改代码，现已修复。

### 按键（功能）

| 按键 | 作用 | 说明 |
|---|---|---|
| **A** | 夹爪**闭合** | 按住持续闭合，松开停住 |
| **B** | 夹爪**张开** | 按住持续张开，松开停住 |
| **X** | **切换控制臂** | 左臂 ↔ 右臂，页面日志 `[L]`/`[R]` 显示当前臂 |
| **Y** | **当前臂回工作位** | 一键回到初始准备姿态 |
| **START** | **重新对齐** | 撞到东西/被顶偏后，重新同步目标，消除漂移 |
| **BACK（按住）** | **冻结 / 急停** | 按住时手臂不动（安全闸），松开恢复 |

### 十字键（D-pad）

| 按键 | 作用 |
|---|---|
| **十字键 ↓** | **整轮重置**：物体 + 双臂 + 夹爪全部回到起始状态 |

## 2. 抓取推荐流程（三点接近法）

> 历史验证结论：**直接斜插成功率 0/7，三点接近成功率 3/3**。一定要走"上方 → 预备 → 抓取"。

1. **选臂**：看物体在机器人**身前偏左还是偏右**
   - 偏左 → 按 **X** 切到**左臂**（日志显示 `[L]`）
   - 偏右 → 按 **X** 切到**右臂**（日志显示 `[R]`）
2. **张开夹爪**：按住 **B** 到全开（默认就是全开）
3. **走到物体正上方**：左摇杆推前 + **LT** 微降，让夹爪停在物体**上方约 10 cm**
4. **对准**：用右摇杆调整手腕角度，让两个指垫**平行于物体两侧面**
   - 药盒：指垫要贴在**大平面**上（夹爪闭合方向 = 世界 Y 轴）
   - 药瓶：指垫贴住圆柱侧面
5. **下压到抓取位**：**LT** 慢慢下降，直到指垫与物体接触面平齐（物体高度中点）
6. **闭合夹爪**：按住 **A**，直到两侧指垫都夹住物体（不要夹太猛，听到"接触"即可）
7. **抬起**：**RT** 上升 10–20 cm，观察物体是否跟着走
8. **搬运**：左摇杆移动到木筐上方
9. **放下**：**LT** 下降到位，按住 **B** 张开，抬升撤离

## 3. 安全与限位

| 保护 | 说明 |
|---|---|
| **速度上限** | 平移 0.30 m/s，旋转 1.20 rad/s（满摇杆） |
| **工作空间盒** | 末端被限制在工作位附近 ±0.55 m（水平）/ ±0.45 m（竖直），防止甩出去 |
| **底座锁定** | 底盘全程钉死，只动手臂（避免历史记录里 24 cm 漂移） |
| **急停** | 按住 **BACK** 立即冻结 |
| **过载** | 关节力矩有限幅（大关节 ±60、腕部 ±30 N·m），顶不动会自己停在限位 |

## 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| **手柄没反应** | 手柄休眠了 → **动一下摇杆**唤醒；或按 START 重连目标 |
| **机器人不动** | 检查是否按住了 **BACK**（冻结）；看日志 fps 是否正常 |
| **动作方向不对** | 告诉我，我改轴映射（可整体翻转某个方向） |
| **末端追不上目标（日志 err 很大）** | 摇杆推太猛或撞到东西 → 松摇杆、按 **START** 重同步；必要时 **Y** 回工作位 |
| **夹爪夹不住** | 三点接近没走对 → 重新对准；闭合时保证两指同时接触 |
| **夹住后下滑** | 历史已知现象（摩擦模型）→ 夹紧后尽快抬升/搬运 |
| **页面没刷新** | 程序默认开启渲染；若卡顿可加 `--no-render` 只跑后台 |
