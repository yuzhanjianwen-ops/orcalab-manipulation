## 一、结论（一句话）

**相机不是"没打开"，而是这个场景里根本没有相机。**

OrcaStudio 端只有 3 个**相机占位 body**，MuJoCo 模型里 `<camera>` 数量为 **0**，
所以没有任何可推流的相机对象，7070/7071 端口永远不会监听。

---

## 二、实测证据

### 1. 模型层：没有相机

```
ncam    = 0      <- MuJoCo 相机数，0
nsensor = 0      <- 传感器数，0
nsite   = 3
nbody   = 63
ngeom    = 97
```

XML 里 `<camera` 出现次数：**0 次**（全文件搜索）

### 2. body 层：只有占位

```
[13] dual_arm_collaborative_service_robot_1_camera_head_body1
[14] dual_arm_collaborative_service_robot_1_camera_head_body2
[22] dual_arm_collaborative_service_robot_1_camera_left_body1
[23] dual_arm_collaborative_service_robot_1_camera_left_body2
[39] dual_arm_collaborative_service_robot_1_camera_right_body1
[40] dual_arm_collaborative_service_robot_1_camera_right_body2
```

这 6 个 body 每个下面只挂了一个 **半径 1.7 mm 的球体占位 geom**
（`size="0.001695358 ..."`，`group="0"`），**不是真实相机**。
它们只是标出了"未来相机该装在哪"的位置。

### 3. 端口层：从未监听

```
7070: False
7071: False
```
整机 39 个监听端口里**没有任何相机 WebSocket 服务**。

### 4. RPC 层：通道是通的，但没有可激活对象

`u.stub` 上确实有相机 RPC：

```
SetCameraSensorInfo        <- 激活推流（关键）
MakeCameraViewportActive   <- 把某相机设为主视口
GetCameraFramePNG          <- 抓单帧 PNG
```

实际调用 `SetCameraSensorInfo`（**成功发出去了**，不是网络问题）：

```
actor_name='dual_arm_collaborative_service_robot_1'  -> status=1  err='Camera actor name not found'
```

穷举 21 个候选 `actor_name` **全部** 返回 `Camera actor name not found`：

```
dual_arm_collaborative_service_robot_1 / _anchor / _Anchor
camera_head / camera_left / camera_right
CameraHead / Camera_Head / head_camera / camera
<robot>.camera_head / <robot>/camera_head
camera_head_body1 / <robot>_camera_head_body1
OrcaCamera / orca_camera / Robot / robot / g1
```

含义：**Studio 端的 actor 表里没有注册任何相机 actor**。

## 三、为什么之前文档说要调 SetCameraSensorInfo

`orca_gym.environment.euler.orca_gym_euler_env.py` 的文档字符串写：

> Studio 端 MuJoCo `<camera>` 默认不推送 WebSocket RGB/Depth 流，
> 必须通过本方法显式激活后，对应端口（如 7070/7071）才会监听并推流。

这段**是对的**，但它有个前提：**场景里得先有 `<camera>`**。
本场景连相机都还没建，所以第一步就卡住了 —— 不是"忘了激活"。

---

## 四、需要在 OrcaStudio 里做的事（客户端无法绕过）

`sensor_info` 是 Studio 侧的配置，Python 客户端只能"激活已存在的相机"，
**不能创建相机**。需要在 OrcaStudio 里：

1. 给机器人（或场景）**添加相机组件**
   - 位置就放在现有那 3 个占位 body 处：
     - `camera_head`（头部）— 有 body2，带姿态，是完整相机
     - `camera_left`（左腕）
     - `camera_right`（右腕）
   - 注意：`camera_right` **只有 body1、没有 body2**，可能是没配完

2. 设置相机的 **user 属性端口**
   - 第 1 个端口 = RGB（即 `color_port`）
   - 第 2 个端口 = Depth（即 `depth_port`）
   - 约定用 7070 / 7071

3. 保存场景

之后客户端执行：

```python
import mjc_message_pb2 as mp
req = mp.SetCameraSensorInfoRequest(
    actor_name="<Studio 里那个 actor 的名字>",
    capture_rgb=True, capture_depth=False,
    save_mp4_file=False, use_dds=False,
    color_port=7070,
)
u.loop.run_until_complete(u.stub.SetCameraSensorInfo(req))
```

端口 7070 开始监听后，用官方封装接图：

```python
from orca_gym.sensor.rgbd_camera import CameraWrapper
cam = CameraWrapper(name="camera_head", port=7070)
cam.start()
while not cam.is_first_frame_received(): time.sleep(0.1)
frame = cam.image          # numpy BGR (H, W, 3)
```

## 五、采集中间件不受影响

`2026-09-23-datacollect/` 已按**相机解耦**设计：

```python
rec.set_image_fn(lambda: cam.image)   # 不注入 -> 无 image 字段，采集照常
```

**实测：不接相机也能完整采集**（52 项测试全通过），只是 episode 里没有图像字段。
相机一旦通了，注入一行即可，**核心逻辑不用改**。
