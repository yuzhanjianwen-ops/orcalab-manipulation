## 三、共用路径推导规则

```
scripts/
├── teleop/     <- teleop.py, gamepad.py, keypad.py, ...
└── collect/    <- collect.py 由此推导出 ../teleop
```

`collect.py` 依赖的兄弟目录关系：

```python
TELEOP_DIR = os.environ.get("ORCA_TELEOP_DIR") or \
             os.path.join(os.path.dirname(HERE), "teleop")
```

**因此：`scripts/teleop` 与 `scripts/collect` 必须保持兄弟关系。**
仅移动其中一个是**不支持**的；如需分离，用环境变量：

```powershell
$env:ORCA_TELEOP_DIR = "<你的路径>\teleop"
```
