# 键盘遥操作 使用说明书

> 适用：OrcaLab 双臂遥操作 `teleop.py --keyboard`
> 版本：2026-09-26
> 对应文件：`keypad.py` / `teleop.py`

---

## 一、启动

```powershell
cd <项目目录>
& "<你的orcalab环境>\python.exe" -X utf8 -u teleop.py --keyboard --flip-lr
```

* `--keyboard` 切换到键盘驱动（不加则用手柄）
* `--flip-lr` 相机在机器人背后时使用（你当前的现场配置）

> 两个参数可以自由组合。手柄和键盘是**二选一**，在启动时决定。

## 二、键位总表

### 2.1 运动控制

| 键盘 | 手柄 | 作用 |
|---|---|---|
| W / S | 左摇杆前后 | 手臂前伸 / 后收 |
| A / D | 左摇杆左右 | 手臂左移 / 右移 |
| R / F | RT / LT | 手臂上升 / 下降 |
| ↑ / ↓ | 右摇杆前后 | 俯仰 Pitch |
| ← / → | 右摇杆左右 | 偏航 Yaw |
| E / Q | RB / LB | 滚转 Roll 正 / 负 |

### 2.2 功能键

| 键盘 | 手柄 | 作用 |
|---|---|---|
| Z | A | 夹爪闭合 |
| X | B | 夹爪张开 |
| C | X | 切换手臂（左 ↔ 右） |
| V | Y | 回工作位 |
| T | START | 重新同步 |
| SPACE | BACK | 急停（按住） |
| G | R3 | 切换视角 |

### 2.3 十字键（数据采集）

| 键盘 | 手柄 | 作用 |
|---|---|---|
| I | 十字上 | 开始 / 结束录制（按一下切换） |
| K | 十字下 | 待命 / 取消 / 中止 |
| J | 十字左 | 保存本次 episode |
| L | 十字右 | 丢弃本次 episode |

### 2.4 速度档

| 按住 | 速度 |
|---|---|
| （不按） | 100% |
| SHIFT | 25% |
| CTRL | 10% |

SHIFT 与 CTRL **可叠加**：同时按住 = 10%。

## 三、双手分区

```
        左手区                      右手区
   ┌──────────────┐          ┌──────────────┐
   │  W  (前伸)   │          │  ↑  (Pitch)  │
   │ A S D        │          │ ← ↓ → (Yaw)  │
   │  (左右/后收) │          │              │
   │  R (升) F(降)│          │  E / Q (Roll)│
   └──────────────┘          └──────────────┘
        拇指: SHIFT / CTRL 降速
```

左手管**平移**，右手管**姿态**，两个物理区域分开，双手不用抢键。

## 四、典型操作流程

### 4.1 移动到目标上方

1. 满速按 W，把手臂前伸到药盒上方附近
2. 按 A / D 微调左右对准
3. 按 R / F 调高度

### 4.2 精细接近（关键步骤）

4. **按住 SHIFT**，速度降到 25%，慢慢靠近
5. 快接触时**再按住 CTRL**，速度降到 10%，做最后几毫米微调

### 4.3 抓取

6. 按 **Z** 闭合夹爪
7. 按 **R** 抬起，观察是否稳定夹住

### 4.4 切换手臂

8. 按 **C** 切换到另一只手臂，重复上述流程

## 五、重要特性与注意事项

### 5.1 松手会有轻微"滑行"

`msvcrt` 只能读到"有键按下"，**读不到"松开了"**。
因此代码用 **0.25 秒超时窗口**推断松手：

* 按住时系统以约 30 Hz 连续产生字符 → 视为按住 ✅
* 松手后 0.25 秒内仍视为按住 → 会**多走一小段**才停 ⚠️

**应对**：靠近目标时提前降到 SHIFT / CTRL 档，滑行距离会明显变小。

### 5.2 按键冲突（Ghosting）

普通键盘同时按住 3~4 个键后可能出现"某些键失效"。
若发现同时按的几个键有的没反应，即为此现象。
**应对**：减少同时按键数量，或改用支持全键无冲（NKRO）的键盘。

### 5.3 手柄与键盘不能同时用

`teleop.py` 在启动时二选一（`--keyboard` 决定），运行时不能热切换。

### 5.4 急停

按住 **SPACE** 冻结当前动作。这是"按住"型，松开即恢复。

## 六、故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 按键盘没反应 | 没加 `--keyboard` | 启动时加该参数 |
| 方向相反 | 相机位置变了 | 加/去掉 `--flip-lr` |
| 松手后走太远 | 满速滑行 | 用 SHIFT / CTRL 降速 |
| 某方向键失效 | 按键冲突 | 减少同时按键 |
| 十字键上下反了 | 约定不一致（见下） | 报给开发者核查 |

## 七、给开发者的备注：十字键方向约定

十字键的"上/下"语义依赖 `gamepad.py` 的约定：

```python
dpad = ( RIGHT - LEFT ,  UP - DOWN )
```

即 **`dy = +1` 表示按下了「上」**。

2026-09-26 曾发现 `keymap.py` 把这里写反（按「上」触发待命、按「下」触发录制），
已修复并同步修正测试。**首次真机使用请重点确认这一条。**
