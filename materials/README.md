# materials — 交付辅助材料

本目录存放**非代码**的交付附件，用于向甲方/同事说明现场情况。

建议放置内容：

| 子目录 | 内容 |
|---|---|
| `screenshots/` | 界面截图、穿模前后对比图、相机挂载位置图 |
| `videos/` | 现场操作录像、抓取演示 |
| `logs/` | 关键运行日志（如需归档） |

## 说明

- 代码与文档**不放这里**：代码在 `scripts/`，文档在 `docs/`。
- 大文件（视频）如体积过大，建议改放外部网盘，在此目录留 `LINKS.md` 记录链接。
